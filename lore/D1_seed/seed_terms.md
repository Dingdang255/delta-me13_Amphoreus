# D1 · 种子义项表

> 硬约束：**禁止笼统使用「种子」**。下文所有条目必须用义项 id（S-A…S-E）引用。

## 结论先行

在 4.6.0 中文文本表的全部 **18 条含「种子」的可定位记录**中：

| 义项 | 出现次数 | 结论 |
|---|---|---|
| **S-B 记忆种子** | 14 | 官方主用法；指德谬歌累积的、由每世昔涟讲述所喂养的心识/数据 |
| **S-C 修辞（花种/胚芽）** | 4 | 纯比喻；**不得当机制** |
| **S-A 演算种子（随机种子）** | **0** | 官方文本中**不存在**「随机种子 / 初始 seed」的表述 |
| **S-D 十二因子投放** | 0（「种子」不用于此义） | 官方用的是「投入十二因子」，不是「种子」 |
| **S-E 火种/权柄** | 0（不混用） | 「火种」与「种子」在原文中从不互换 |

> **对项目的直接影响**：D1 的「种子层」若指 S-A（随机种子），则**没有一手依据**，必须标 `UNKNOWN` / `inferred`；本项目此前把「种子」当作 `seed → world` 的输入，是对 S-B 的**隐喻误读**，已在 `10_conflicts.jsonl` 记为 CF-004。

## S-A　演算种子（随机种子 / 初始条件）

| 项 | 内容 |
|---|---|
| 定义 | 实验启动时的随机种子或初始条件 |
| 官方是否明说 | **否**。全部 18 条「种子」记录均不指此义 |
| 近似表述 | 官方用「初始变量」（无机生命 / 有机生命 / 人科人属 / 古典文明），不是「种子」 |
| 证据 | `S-001:424993`、`S-001:424995`、`S-001:424997`、`S-001:424999` |
| 置信度 | **A（否定性事实：官方无此表述）** |
| 处置 | 任何 `seed` 输入建模都只能标 `inferred`；不得写成官方机制 |

## S-B　记忆种子（德谬歌的心识 / 「最初的智种」）

| 项 | 内容 |
|---|---|
| 定义 | 每世昔涟在格式化前讲述逐火之旅，内容被权杖归档，德谬歌从中学习成长，形成「记忆的种子」 |
| 逐字 | 「在德谬歌监牢，在格式化进程完成前，每个轮回的昔涟都会向权杖讲述逐火之旅的故事。于是，「记忆的种子」诞生。」 |
| 证据 | `S-001:122494`、`S-001:122503`、`S-001:122505`、`S-001:122506`、`S-001:122507`、`S-001:122508`、`S-001:122512`、`S-001:122515`、`S-001:122555` |
| 补充 | `S-001:225857`「世界是从一枚『种子』中发芽的。它长成名为『翁法罗斯』的大树」——此处「种子」仍是 S-B 的宇宙论修辞化 |
| 置信度 | **A** |
| 关联 | 德谬歌（CHR-003）、迷迷（CHR-004）、无漏净子（CHR-005） |

## S-C　花种 / 胚芽（修辞）

| 项 | 内容 |
|---|---|
| 定义 | 纯比喻，如「栽下记忆的种子，让往昔的花朵在明日绽放」「接住破碎的胚芽」「就像种子即将死去」 |
| 证据 | `S-001:53289`、`S-001:159443`、`S-001:159456`、`S-001:159554`、`S-001:159560` |
| 置信度 | **A（作为文本存在）/ 不得当机制（R2）** |
| 处置 | 只进 `community`/`inference`，不进 D1 机制表 |

## S-D　十二因子投放

| 项 | 内容 |
|---|---|
| 定义 | 实验启动时「投入十二因子」作为初始变量 |
| 逐字 | 「投入十二因子后，以无机生命为初始变量，进行的第1至50121次循环。」（`S-001:424993`） |
| 与 S-A 的关系 | **无官方文本把「因子」称为「种子」**；二者只能通过「初始条件」这一上位概念相连，属推断 |
| 置信度 | **A（投放事实）/ 推断（与 S-A 等价）** |

## S-E　火种 / 权柄

| 项 | 内容 |
|---|---|
| 定义 | 十二泰坦神权的载体、再创世燃料 |
| 与「种子」的关系 | 原文中**从不互换**；「火种」有独立计数（十二枚/轮、四亿枚峰值） |
| 证据 | `S-001:424932`、`S-001:425102`、`S-001:75058` |
| 置信度 | **A** |

## 引用守则

1. 写「种子喂养德谬歌」→ 必须写成 `S-B`。
2. 写「实验以随机种子启动」→ 只能写 `S-A(UNKNOWN)`，并附「官方无此表述」。
3. 写「种子长成世界」→ 标 `S-C`（修辞）。
4. 写「十二因子是种子」→ 禁止；应写 `S-D` 并注明这是推断。
