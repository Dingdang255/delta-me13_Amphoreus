# ADR-0002：原著还原层与零专名边界

* 状态：**已采纳**
* 日期：2026-10-31
* 适用：新增的 `lore/` 考据层、`apps/canon.py` 等通用求值器、`presets/canon*` 与 `worlds/generated/`
* 关联：[项目全面梳理与问题诊断-2026-10-30.md](../../.trae/documents/项目全面梳理与问题诊断-2026-10-30.md)、[全面修改执行计划-2026-10-30.md](../../.trae/documents/全面修改执行计划-2026-10-30.md)、[信息采集提示词-翁法罗斯全维考据-v1.md](../../.trae/documents/信息采集提示词-翁法罗斯全维考据-v1.md)

---

## 1. 背景

项目当前有两条互相拉扯的约束：

1. **引擎必须通用**：`kernel/` 与 `apps/` 里不许出现任何专有名词（红线 1），
   `docs/使用教程.md` 也明写「不模拟地图、对话、战斗、城邦」。
2. **还原必须完整**：要让剧情、对白、角色心智、逐轮日志、终端输出都立得住，
   就必然需要大量专名、台词与人物文本。

把专名塞进 `apps/` 会破坏红线 1；把内核改成原著专用会破坏可复现性与跨世界泛化。
两者都不能选。

---

## 2. 决策

**新增一个只读的「考据 / 语料」层，把专名与文本关在数据里；程序侧只保留通用求值器。**

| 层 | 位置 | 是否允许专名 | 职责 |
|---|---|---|---|
| 考据层 | `lore/`（原始证据 + `lore/canon/` 编译产物 + `lore/schema/`） | **允许** | 事实、来源、冲突、未知、角色卡、场景、对话、日志、终端、微变量 |
| 内核 | `kernel/` | 禁止 | 演化与记账（**本 ADR 不授权任何修改**） |
| 通用求值器 | `apps/canon.py`、后续 `worldgen/trends/agents/dialogue/logs/scenes/fidelity` | 禁止 | 只认 id、枚举与数值；不认任何名字 |
| 只读叙事 | `apps/terminal.py`、`apps/archive.py`、`apps/origin.py` | 禁止 | 把语料渲染成终端 / 档案 / 报告 |
| 世界数据 | `presets/canon*`、`worlds/origin/presets/canon-eternal`、`worlds/generated/` | **允许** | 绑定名字、顺序、开关 |
| 呈现 | `apps/render.py`、`apps/viz.py` + 词表 | 允许（只读） | 展示 |

### 2.1 三个运行档位

| 档位 | 行为 | 用在哪 |
|---|---|---|
| `off` | 不读 `lore/canon/`，现有轨道逐帧不变 | `plot` / `plot-full` / 既有世界（默认） |
| `suggest` | 读语料、产出建议投递，但不写状态 | `presets/canon`、`canon-eternal`（默认） |
| `drive` | 建议投递经 `apps/script.py` / `inject` 真正进入世界 | `presets/canon-drive`、`worlds/generated/` |

**默认必须是 `off`。** 任何让既有预设读到语料的改动，都视为改轨迹。

---

## 3. 零专名边界（可执行）

`tools/grep_forbidden.py` 的扫描集合**不扩大**，仍是 `kernel/` 与 `apps/`；
本 ADR 只是把「专名能放哪」写清楚：

| 允许 | 不允许 |
|---|---|
| `lore/**`（含 `lore/canon/characters/*.json`） | `kernel/**` 的任何一行（含注释与 docstring） |
| `presets/**`、`worlds/**` | `apps/**` 的任何一行（含注释与 docstring） |
| `docs/**`、`tests/**` 的测试数据 | `tools/**` 除语料工具外的脚本中硬编码的剧情文本 |

推论：`apps/canon.py` 只能出现英文注释与 id；角色名一律以 `CHR-###` 形式传入。

## 4. 冻结清单

### 4.1 本次一行不改

| 路径 | 说明 |
|---|---|
| `kernel/**` | 需要第 9 个系统调用或改随机流时，先新增 ADR 并单独立项 |
| `config/loci.json` | 位表与固定耦合 |
| `config/params.json` | 阈值 / 帧预算 / 判据 |
| `config/mapping.json` | 12×6 泛函 |
| `config/seeding.json` | 播种分布 |
| `config/calendar.json` | 历法 |
| `config/conclusions.json` | 结论表 |
| `config/lexicon.json` | canonical 词表 |

### 4.2 只可追加，不可覆盖

| 路径 | 规则 |
|---|---|
| `docs/wiki/**` | 新抓取另起文件；旧文件保留为历史证据 |
| `lore/**` | 新增条目可以；改既有条目必须走 `13_changelog.md` |
| `CHANGELOG.md` | 只追加未发布节 |

### 4.3 条件冻结

| 路径 | 规则 |
|---|---|
| `tests/golden_fingerprints.json` | 只有「会改轨迹」的变更获批后才可重写；重写必须单开一轮并签字 |
| `tests/baseline.json` | 只由 `tools/baseline.py --write` 生成；不允许手改 |

### 4.4 允许新增轨迹变化的容器

以下位置可以改出不同的轨迹，**且不得写回 canonical**：

* `presets/canon-drive/**`
* `worlds/origin/presets/canon-eternal/**`（若自带 `genesis.json`）
* `worlds/generated/**`（本地生成，不入库）

## 5. 数字的唯一来源

所有文档里的版本号、模块数、预设数、指纹条数、语料规模，一律以
[`tests/baseline.json`](../../tests/baseline.json) 为准：

```powershell
python tools\baseline.py --check     # 只读；漂移则退出码 1
python tools\baseline.py --write     # 仅在确认变更后重写
```

字段形如 `{"value": ..., "method": ...}`，`method` 写明该数字是**怎么数出来的**
（静态计数 / 工具输出 / 文件哈希），避免再次出现「6/6 与 8 条」「68 与 93」这类口径分裂。

---

## 6. 证据与诚实条款

| 标签 | 含义 | 允许出现在 |
|---|---|---|
| `official` | 官方逐字（客户端文本表 / 任务概述 / 阅读物） | 事实栏 |
| `reconstructed` | 依据确定性规则从官方数据重建 | 事实栏，必须带标签 |
| `inferred` | 推理补全 | 只能进 `inference` 字段 |
| `UNKNOWN` | 已检索但未取得 | 未知表与缺口表 |

三条硬规则：

1. **官方文本里没有「随机种子」**（`lore/D1_seed/seed_terms.md`：18 条含「种子」的记录中 0 条指随机数）。
   任何 `seed → world` 的实现只能标 `inferred`，不得写成官方机制。
2. **33,550,336 轮里官方只记录 35 轮**；逐轮日志只能是「官方锚点 + 重建规则」，不得声称逐轮真跑。
3. **同人与二手解析永不进事实栏**；`fanwork: true` 仅存在于 `lore/D7_community/`。

## 7. 后果

**正面**

* 红线 1 不变：`grep_forbidden` 仍是 0 命中。
* canonical 可复现：既有预设不读语料，指纹不动。
* 还原内容可追溯：每条运行数据都能回答「来源 / 对应事实 / 谁实现 / 谁守」。

**负面 / 代价**

* 出现第三个数据层（`lore/`），需要编译步骤与契约测试。
* 语料与实现之间多了一次 `lore_compile`，忘记重编会出现「数据改了但 canon 没变」。
  用 `python tools\lore_compile.py --check` 守住。
* 语料规模会随采集增长，`tests/baseline.json` 的 `lore.counts` 会持续漂移，
  需要接受「每次语料变更都更新基线」。
