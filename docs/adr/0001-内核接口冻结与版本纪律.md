# ADR-0001：内核接口冻结与版本纪律

* 状态：**已采纳**
* 日期：2026-10-07
* 适用：`kernel/api.py`（内核的系统调用门）、`kernel/` 全体、`apps/` 全体

---

## 1. 背景

§3.1 把仓库切成两个物理包（`kernel/` 纯逻辑内核、`apps/` 用户态），§3.2 把内核的对外面
收敛成 **8 个系统调用**。分层解决了"谁依赖谁"，但没解决**"对内承诺什么"** ——
只要接口还能随手长，用户态就会一点点把内核重新拽回去：多一个 hook、多一个
"反正只有应用会调"的私有入口，最后 `kernel/` 又变成一堆只有 `run.py` 知道怎么拼的零件。

故本 ADR 定一件事：**内核的对外面是冻结的**。冻结的收益不是"好看"，而是三条可检验的性质：

1. **可替换**：只要 8 个调用的语义不变，`apps/` 可以整体重写而不动内核。
2. **可判版本**：应用能问 `version()` 决定自己能不能跑在这台内核上，而不是靠 try/except 猜。
3. **可审计**：`kernel/` 里冒出一个"给应用用的"新入口，评审时是一个**显式决定**，
   而不是一次顺手。

---

## 2. 决策：对外只有 8 个调用

| # | 调用 | 语义 |
|---|---|---|
| ① | `load(machine_spec) -> Session` | 用**机器规格**建一个世界（预设名，或一张规格表） |
| ② | `session.step(n=None) -> Trajectory` | 推进**最多** n 帧；可分段调用 |
| ③ | `session.snapshot() -> Snapshot` / `session.restore(h) -> Session` | 存档 / 读档 |
| ④ | `session.inject(disturbance) -> dict` | 投递**外生**扰动 —— 唯一能打破闭环的入口 |
| ⑤ | `session.observe() -> dict` | 【只读】观测快照 —— 条件能读到的全部 |
| ⑥ | `session.events() -> EventStream` | 事件流（`emit()` 的消费侧） |
| ⑦ | `session.capabilities() -> dict` | 声明可用算子 / 可投递能力 / 权限表 |
| ⑧ | `version() -> str` | 内核接口版本 |

**这就是全集。** 内核里再有别的函数（`kernel.core._advance`、`kernel.loader.DataSet` …），
都是**实现**，不是接口：应用可以读，但一旦依赖它们的具体形状，就等于把内核的实现细节
写进了用户态 —— 那种依赖不受本 ADR 保护，改实现时不会为它留兼容。

### 8 个之外的入口一律不许加

想加第 9 个之前，先回答**一个问题**并留下证据：

> **现有 8 个的组合为什么做不到？**

把答案写成 `docs/adr/000N-<标题>.md`，评审通过才动手。答不上来 ⇒ 说明该加的是
**应用层的一个模块**，不是内核的一个调用。

反例（都该在应用层解决）：

* "再加一个 `session.advance_one_frame()`" —— `step(1)` 就是它。
* "再加一个 `session.set_state(st)`" —— 那是 `restore()` 的变体，或者干脆是 `inject()`。
* "再加一个 `session.on(...)` 事件钩子" —— 事件回调是 `load({"on_event": …})` 的规格项，
  不是第 9 个调用。

## 3. 版本号纪律

### 3.1 版本从哪来

`kernel.api.API_VERSION` 是**唯一**的版本源，`version()` 返回它，`capabilities()["api_version"]`
也返回它。应用不得自行硬编码一个"我以为的内核版本"。

### 3.2 什么算破坏性变更（必须升 major）

* 删除或重命名任何一个系统调用；
* 改变任何一个调用的**签名**（位置参数顺序、必填性）；
* 改变返回值**类型或字段**（`Snapshot` 的字段、`EventStream` 的 `(frame, kind, payload)` 形状、
  `observe()` 里**删掉或改名**已有的键）；
* 改变**语义**（哪怕签名不变）：例如 `step(n)` 的 n 从"相对帧数"改成"绝对帧号"、
  `inject()` 的默认落点从"下一帧"改成"当帧"、`snapshot()` 不再携带待触发清单。

### 3.3 什么不算破坏性变更（同 major，但必须记 CHANGELOG）

* `observe()` **新增**键（条件语言随之多一个可读量）；
* `capabilities()` 新增算子 / 能力 / 权限（它是**注册表快照**，本来就该随配置变）；
* 新增内核会 `emit()` 的**事件类别**（`kernel/vocabulary.py::EVENT_KINDS`）——
  订阅方写旧类别照旧工作；
* 新增预设字段、新增 `script.jsonl` 的动作写法；
* `load()` 的 `machine_spec` **新增**可选键。

判据一句话：**"已经写好的应用不用改一个字，还能照常跑"** ⇒ 非破坏。

### 3.4 破坏性变更怎么发

1. `API_VERSION` 升 major（`"1"` → `"2"`）；
2. `CHANGELOG.md` 里**显式声明**"本版为破坏性变更"，并写清哪一条、改成什么；
3. 若同时动了演算语义，按《重构计划》§5 的指纹重写流程走（归档旧指纹 → 重算 → 回填 timeline）。

## 4. 冻结的边界在哪

冻结的是**内核的对外面**，不是内核的每一行：

| 属于接口（受本 ADR 保护） | 属于实现（不受保护） |
|---|---|
| 8 个调用的签名与语义 | `_advance` / `Operators` / `Scheduler` 的内部结构 |
| `Snapshot` 的字段名 | `State` 的字段与 `digest()` 的算法 |
| `observe()` 的键名与口径 | `obs_now()` 的构造顺序 |
| `EventStream` 的记录形状 | `Trajectory` 上除 `records` 外的属性 |
| `_SPEC_KEYS` 里那张规格表 | `DataSet` 的内部索引（`_by_frame` / `onsets` …） |

`observe()` 的口径与内核主循环的 `obs_now()` **逐字同源** —— 这不是实现细节，
而是"应用的条件"与"预设的 `when`"说同一门语言的前提，故它在接口这一侧。

---

## 5. 怎么保证它不被悄悄违反

| 防线 | 位置 | 拦什么 |
|---|---|---|
| 模块登记簿 | `tools/layer_lint.py` 的 `KERNEL` / `APPS` | `kernel/` 冒出新模块、或内核 import `apps` |
| 专名扫描 | `tools/grep_forbidden.py` | 引擎代码写死剧情名词 |
| 逐步推进 | `tools/stepwise_lint.py` | 解析求解 / 预读未来 |
| 版本号 | `API_VERSION` + `capabilities()` | 应用能自查；改 major 必留 CHANGELOG |
| 本 ADR | 评审 | 第 9 个调用的"为什么组合不出来" |

登记簿是**棘轮**：基线只许减不许增。新增一个内核模块或一条越界，`layer_lint` 直接红。

## 6. 附：最小用法

```python
from kernel.api import load, version

sess = load({"preset": "plot", "seed": 0,
             "runtime": services.default(),      # 服务实现束（应用交来）
             "namer": namer,                     # 不透明句柄，内核不调用
             "rules": conditions.evaluate})      # `when` 的谓词（应用交来）

print(version())                 # "1"
sess.step(1000)                  # 走到第 1000 帧
h = sess.snapshot()              # 存档
sess.step(500)
sess.restore(h)                  # 回到第 1000 帧（事件流一并截回）
sess.inject({"capability": "emit", "payload": {"event": "manual"}})
sess.step(1)

for frame, kind, payload in sess.events():
    print(frame, kind)
```
