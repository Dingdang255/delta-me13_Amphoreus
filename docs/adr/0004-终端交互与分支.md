# ADR-0004：终端交互 —— 默认作答、可选询问、分支与回归主线

* 状态：**已采纳**
* 日期：2026-10-31
* 适用：`apps/terminal.py`、`apps/terminal_window.py`、`presets/*/messages.jsonl`、`apps/script.py`
* 关联：[ADR-0003](0003-表现层双通道.md)

---

## 1. 背景

现在的 `messages.jsonl` 已支持 `prompt` + `options` + `default`：

* 非 TTY（或不加 `--terminal-ask`）时用 `default` 直接继续；
* 加 `--terminal-ask` 时在该点等待输入，超时回落默认。

缺的是两件事：

1. 选项**没有后果** —— 选什么都只影响那一行回显，不影响后续内容；
2. 互动点没有"回到主线"的约束 —— 一旦允许分支，很容易把剧情带飞。

---

## 2. 决策

### 2.1 两条运行路径

| 路径 | 触发 | 行为 |
|---|---|---|
| **默认（非交互）** | 不加参数 | 每个 `prompt` 用 `default` 自动作答，立即继续；作答写入 ledger |
| **交互** | `--terminal-ask` / `--ask` | 在 `prompt` 处等待；非法输入重问；超时（默认 60s）或非 TTY 回落 `default` |

两条路径**答完同一个问题后走同一条分支**，差别只是在不在那儿停。

### 2.2 选项结构化（向后兼容）

```json
{"id": "TRM-003", "frame": 120,
 "text": ">>>来自未知发布者的程序 ",
 "kind": "prompt",
 "ask": "是否允许写入？",
 "options": [{"id": "deny", "label": "保持沉默"},
             {"id": "allow", "label": "（成像）"}],
 "default": "deny",
 "on_choice": {
   "deny":  {"jump": "TRM-005", "rejoin": "TRM-012"},
   "allow": {"jump": "TRM-006", "inject": {"capability": "write_memory",
                                            "payload": {"actor": "SYS-002"}},
             "rejoin": "TRM-012"}
 }}
```

* `options` 仍接受旧的字符串数组：字符串本身即 `id`，`label` 同值；
* `default` **必填**（没有默认值的 prompt 不允许出现在只读轨道里）；
* `on_choice` 键必须是 `options` 的 id 子集。

### 2.3 分支语义

| 字段 | 含义 |
|---|---|
| `jump` | 跳到另一条消息 id；不写则继续按 `frame` 顺序 |
| `inject` | 只在 `drive` 档生效；等价于 `apps/script.py` 的一次投递 |
| `rejoin` | **必填**：分支必须在有限步内回到这条主线消息 |
| `branch_depth` | 单条分支允许连续偏离的消息条数，默认 **3** |

约束（由 linter 强制）：

1. 每个分支节点必须能从 `jump` 出发、在 `branch_depth` 内到达 `rejoin`；
2. 分支不得跳过任何 `assert` / 必需的 `emit` 锚点；
3. 分支只能改"显示哪条消息"，不能改裁决、时刻、席位 —— 这仍然由演算决定。

### 2.4 自由分支（例外）

预设可在 `narrative.branch_policy` 声明：

| 取值 | 含义 | 用在哪 |
|---|---|---|
| `"mainline"`（默认） | 必须声明 `rejoin`，偏离 ≤ `branch_depth` | `plot` / `plot-full` / `canon` |
| `"free"` | 不要求 `rejoin`，允许长分支 | 涌现版、`worlds/generated/` |

`free` 不是"随便写"：仍不许写状态、不许改裁决，只是允许叙事线程分叉。

### 2.5 确定性与回放

* 每次作答记录 `{frame, message_id, option_id, source: "default" | "user" | "timeout"}`；
* `--log` 落盘的 ledger 可在重放时优先读取，**不重复询问**；
* 同一 ledger + 同一预设 ⇒ 逐条消息一致。

---

## 3. 与只读红线的关系

* 终端层仍不写 `st`，`TerminalFeed.__call__` 恒为 `True`；
* `inject` 只在 `drive` 档、且只经既有 `apps/script.py` / `session.inject()`，不新增内核入口；
* 删掉终端层，演算逐帧不变 —— 分支只影响"读到哪条文本"。

---

## 4. 后果

**正面**

* 默认路径零打扰：不加参数就能一直跑到结束；
* 互动点有明确的"回主线"约束，不会把剧情带飞；
* 答案可记录、可重放，验收可复现。

**负面**

* `messages.jsonl` 的校验复杂度上升（分支可达性、默认值、锚点不跳过）；
* 分支图要维护 `rejoin`，写错会在 linter 阶段才暴露。

---

## 5. 落地顺序

1. `apps/terminal.py`：解析结构化 `options` / `on_choice`，实现 `BranchCursor`；
2. `tools/messages_lint.py`：默认值必填、分支可达、不跳锚点、深度上限；
3. `tests/test_terminal_branch.py`：默认路径 / 交互路径 / 超时 / ledger 回放 / 非法选项；
4. 预设：先给 `plot-full` 加一条演示分支（不改变事件与指纹），再推广到 `canon`。
